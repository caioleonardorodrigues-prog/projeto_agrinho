# projeto_agrinho
# 🌾 Dificuldades do Campo Entre a Cidade

## Sobre o Projeto
Este site informativo apresenta a vida no campo, destacando **problemas enfrentados pela população rural**, **meios de cultivo**, **veículos agrícolas** e **soluções possíveis**.  

O site é **interativo**, com:
- Galeria de imagens em **slider automático** e controles manuais
- Listagem de problemas e soluções com **efeitos de destaque**
- Formulário de contato com feedback de envio
- Mapa incorporado via Google Maps

O design utiliza **cores neutras e tipografia legível**, pensado na **acessibilidade visual** para pessoas com dificuldades de visão.

---

## Funcionalidades

- Informações detalhadas sobre o campo e plantio
- Slider de imagens com navegação manual e automática
- Efeitos de destaque em problemas e soluções
- Formulário de contato interativo
- Mapa do campo incorporado
- Layout responsivo e acessível
